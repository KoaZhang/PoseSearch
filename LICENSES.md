# Licensing notes

This file is an engineering inventory, not legal advice.

- **PoseSearch project code:** no distribution license has been selected by the repository owner yet.
- **RTMLib code:** Apache-2.0 upstream. PoseSearch pins commit `03a1693e59e4f7cd84582c0fb30459b3bf18ad42` for the first validation baseline.
- **YOLOX-tiny HumanArt / RTMPose-s weights:** model/weight terms must be reviewed separately from RTMLib code licensing before redistribution or commercial packaging.
- **HumanArt training data:** the project specification notes non-commercial-use conditions on the HumanArt data download page. PoseSearch inference does not require downloading the training dataset.

Do not infer model or training-data rights solely from the RTMLib source-code license.
